# 登录页面问题诊断脚本

## 问题：访问 http://localhost:5174/login 无法显示

### 诊断步骤：

#### 1. 检查前端开发服务器是否运行

**在终端执行**：
```bash
npm run dev
```

**预期输出**：
```
VITE v7.x.x  ready in xxx ms

➜  Local:   http://localhost:5173/
➜  Network: use --host to expose
```

**注意**：端口可能是 5173 而不是 5174，请使用实际显示的端口。

---

#### 2. 浏览器控制台检查

1. 打开浏览器开发者工具（F12）
2. 切换到"Console"标签页
3. 访问 http://localhost:5173/login （使用实际端口）
4. 查看是否有错误信息

**可能的错误**：
- ❌ `Failed to fetch` - 后端未启动或端口错误
- ❌ `Module not found` - 文件路径错误
- ❌ `Unexpected token` - 语法错误
- ❌ `Cannot read property` - 运行时错误

---

#### 3. 检查网络请求（如果页面空白）

1. 开发者工具切换到"Network"标签页
2. 刷新页面
3. 查看是否有红色的失败请求

---

#### 4. 常见问题和解决方案

**问题A：页面完全空白，控制台无错误**

可能原因：CSS 样式问题或组件未渲染

**解决方法**：
```javascript
// 在 Login.jsx 最前面添加调试代码
function Login() {
  console.log('Login 组件已加载'); // 添加这行
  const navigate = useNavigate();
  // ... 其余代码
```

---

**问题B：显示 404 页面**

可能原因：路由未正确配置

**解决方法**：
1. 检查 `src/App.jsx` 中是否有 `<Route path="/login" element={<Login />} />`
2. 重启开发服务器（Ctrl+C 然后 `npm run dev`）

---

**问题C：页面卡在加载状态**

可能原因：组件内部有无限循环或阻塞

**解决方法**：
检查 `useEffect` 是否缺少依赖数组

---

**问题D：显示白屏，控制台报错 "authAPI is not defined"**

可能原因：api.js 导出有问题

**解决方法**：
检查 `src/utils/api.js` 文件是否正确创建，并且包含：
```javascript
export const authAPI = {
  login(...) { ... },
  register(...) { ... },
  // ...
};
```

---

#### 5. 快速验证方法

**步骤1**：在浏览器地址栏输入：
```
http://localhost:5173/
```
如果首页能正常显示，说明前端服务正常运行。

**步骤2**：在浏览器地址栏输入：
```
http://localhost:5173/login
```

**预期结果**：应该看到登录页面（紫色渐变背景，白色卡片）

**如果看到**：
- ✅ 登录表单 → 正常
- ❌ 空白页 → 继续下一步
- ❌ 404 → 路由问题
- ❌ 其他页面 → 路由配置错误

---

#### 6. 临时调试版本

如果上述方法都无法解决，可以创建一个简化的测试页面：

**创建文件：src/pages/LoginTest.jsx**
```jsx
function LoginTest() {
  return (
    <div style={{ padding: '2rem', textAlign: 'center' }}>
      <h1>登录页面测试</h1>
      <p>如果你能看到这段文字，说明路由配置正常</p>
    </div>
  );
}

export default LoginTest;
```

**修改 src/App.jsx，临时替换**：
```jsx
import LoginTest from './pages/LoginTest'; // 添加这行

// 在 Routes 中修改：
<Route path="/login" element={<LoginTest />} />
```

如果 LoginTest 能显示，说明是 Login 组件本身的问题。

---

#### 7. 检查文件是否正确保存

**在项目根目录执行**：
```bash
dir src\pages\Login.*
```

**预期输出**：
```
Login.css
Login.jsx
```

如果文件不存在，需要重新创建。

## 最可能的原因

基于您提到的端口是 **5174** 而不是 5173，最可能的情况是：

1. **端口不匹配** - Vite 默认使用 5173，但如果该端口被占用会自动切换到 5174
2. **开发服务器需要重启** - 添加新文件后需要重启 `npm run dev`

**立即尝试**：
```bash
# 停止当前服务器（如果在运行）
Ctrl + C

# 重新启动
npm run dev

# 查看输出的实际端口，然后访问：
http://localhost:{实际端口}/login
```
