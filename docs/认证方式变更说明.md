# 认证方式变更说明

**变更时间**：2025年12月2日  
**变更原因**：企业资格限制，无法使用微信登录功能  
**变更类型**：重大架构调整

---

## 变更概述

将系统的用户认证方式从"微信网页授权登录"改为"普通用户名密码注册登录"。

### 变更前
- 普通用户：通过微信扫码/浏览器内授权登录
- 管理员：通过用户名+密码登录
- 用户数据：存储微信 openid、unionid、昵称、头像等

### 变更后
- 普通用户：通过系统生成的用户名（数字ID）+ 密码登录
- 管理员：保持不变，通过用户名+密码登录
- 用户数据：存储系统生成的用户名、用户设置的昵称、BCrypt 加密的密码

## 技术变更详情

### 1. 数据库变更

#### users 表结构调整

**删除字段**：
- `openid` VARCHAR(100) - 微信 OpenID
- `unionid` VARCHAR(100) - 微信 UnionID
- `avatar` VARCHAR(500) - 微信头像 URL

**修改字段**：
- `username` - 改为 NOT NULL，系统自动生成（从 10001 开始递增）
- `password_hash` - 改为 NOT NULL，存储 BCrypt 加密后的密码
- `nickname` - 改为 NOT NULL，用户注册时设置，用于评论展示

**删除索引**：
- `idx_openid`
- `idx_unionid`

**新增索引**：
- `idx_nickname`

### 2. 后端代码变更

#### 删除文件
- `WeChatService.java` - 微信 API 调用服务接口
- `WeChatServiceImpl.java` - 微信服务实现类

#### 修改文件

**User.java**：
- 删除字段：`openid`, `unionid`, `avatar`
- 保留字段：`username`, `passwordHash`, `nickname`, `roles`, `email`

**UserMapper.java** 和 **UserMapper.xml**：
- 删除方法：`selectByOpenid(String openid)`

  - `String login(String username, String password)` - 用户登录

**UserServiceImpl.java**：

**AuthController.java**：
- 删除接口：`POST /api/auth/wechat/login`

  - `POST /api/auth/register` - 用户注册

**配置文件**：

## 用户注册流程

### 1. 注册流程

```
用户填写昵称和密码
    ↓
前端调用 POST /api/auth/register
    ↓
后端生成唯一用户名（10001, 10002, ...）
    ↓
密码 BCrypt 加密存储
    ↓
返回用户名、昵称和 JWT Token
    ↓
前端显示用户名，提示用户保存
    ↓
自动登录（Token 已返回）
```

### 2. 登录流程

```
用户输入用户名（10001）和密码
    ↓
前端调用 POST /api/auth/login
    ↓
后端验证用户名和密码
    ↓
返回 JWT Token
    ↓
前端保存 Token 到 localStorage
```

### 3. 用户名生成规则

- 起始ID：10001
- 生成方式：查询当前最大用户名 + 1
- 格式：纯数字字符串
- 唯一性：数据库 UNIQUE 索引保证

## 数据迁移

### 已有用户数据处理

如果数据库中已有通过微信登录的用户数据：

1. **迁移脚本**（示例）：
```sql
-- 1. 备份现有用户表
CREATE TABLE users_backup AS SELECT * FROM users;

-- 2. 删除微信登录的普通用户（如需保留，可跳过）
DELETE FROM users WHERE roles = 'ROLE_USER' AND openid IS NOT NULL;

-- 3. 删除废弃字段
ALTER TABLE users DROP COLUMN openid;
ALTER TABLE users DROP COLUMN unionid;
ALTER TABLE users DROP COLUMN avatar;

-- 4. 修改字段约束
ALTER TABLE users MODIFY username VARCHAR(50) NOT NULL;
ALTER TABLE users MODIFY password_hash VARCHAR(255) NOT NULL;
ALTER TABLE users MODIFY nickname VARCHAR(50) NOT NULL;

-- 5. 删除索引
DROP INDEX idx_openid ON users;
DROP INDEX idx_unionid ON users;

-- 6. 新增索引
CREATE INDEX idx_nickname ON users(nickname);
```

2. **保留管理员账号**：
   - 管理员账号（username='admin'）不受影响
   - 继续使用用户名密码登录
