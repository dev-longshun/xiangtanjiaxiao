## 三、HTTP 状态码速查

### 3.1 状态码含义

| 状态码 | 响应 code | 场景 | 对应 Handler |
|--------|---------|------|-------------|
| **200** | 200 | 请求成功，权限校验通过 | N/A（正常处理） |
| **200** | 400 | 请求格式错误或参数不合法 | N/A（业务逻辑） |
| **200** | 401 | 未授权（Token 无效/过期/不存在） | CustomAuthenticationEntryPoint |
| **200** | 403 | 权限不足（已登录但角色不符） | CustomAccessDeniedHandler |
| **200** | 404 | 资源不存在 | N/A（业务逻辑） |
| **200** | 500 | 服务器内部错误 | N/A（异常处理） |

### 3.2 常见错误响应

**401 未授权**：
```json
{
  "error": "未授权",
  "message": "请先登录或提供有效的 Token",
  "status": 401,
  "path": "/api/reviews"
}
```

**403 权限不足**：
```json
{
  "error": "权限不足",
  "message": "您没有访问此资源的权限",
  "status": 403,
  "path": "/api/admin/schools"
}
```

## 五、常见问题排查

### Q1：访问接口返回 401

**可能原因**：
- ❌ 未提供 Token
- ❌ Token 已过期（24小时）
- ❌ Token 已失效（用户已退出）
- ❌ Token 格式错误（缺少 "Bearer " 前缀）

**排查步骤**：
1. 确认 Authorization 请求头存在
2. 确认格式为 `Authorization: Bearer {token}`
3. 重新登录获取新 Token
4. 检查 Token 是否在黑名单中

### Q2：访问接口返回 403

**可能原因**：
- ❌ 用户已登录，但角色不符
- ❌ 用户是 ROLE_USER，试图访问 ROLE_ADMIN 接口
- ❌ Token 中的 roles 字段缺失

**排查步骤**：
1. 确认已成功登录（有 Token）
2. 检查用户在数据库中的 roles 字段
3. 确认 Token 中的 roles 是否正确
4. 使用管理员账号重试

### Q3：管理员无法访问管理接口

**可能原因**：
- ❌ 管理员账号的 roles 不是 ROLE_ADMIN
- ❌ 使用了普通用户 Token

**排查步骤**：
1. 查询数据库：`SELECT username, roles FROM users WHERE username='admin'`
2. 确认 roles 包含 ROLE_ADMIN
3. 用管理员账号重新登录
4. 检查返回的 Token 是否有效

## 六、权限规则快速修改

### 当前规则（SecurityConfig.java）

```java
.authorizeHttpRequests(auth -> auth
    // 公开接口
    .requestMatchers("/api/auth/**").permitAll()
    .requestMatchers("/api/schools/**").permitAll()
    
    // 用户接口
    .requestMatchers("/api/reviews").hasAnyRole("USER", "ADMIN")
    
    // 管理员接口
    .requestMatchers("/api/admin/**").hasRole("ADMIN")
    
    // 其他
    .anyRequest().authenticated()
)
```

### 常见修改场景

**场景1：将某接口改为公开**
```java
// 从
.requestMatchers("/api/reviews/my").hasAnyRole("USER", "ADMIN")

// 改为
.requestMatchers("/api/reviews/my").permitAll()
```

**场景2：新增 SUPER_ADMIN 角色**
```java
// 添加规则
.requestMatchers("/api/super/admin/**").hasRole("SUPER_ADMIN")
```

**场景3：修改权限要求**
```java
// 从
.requestMatchers("/api/reviews").hasAnyRole("USER", "ADMIN")

// 改为（必须是 ADMIN）
.requestMatchers("/api/reviews").hasRole("ADMIN")
```
