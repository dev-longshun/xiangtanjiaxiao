## 前端代码执行流程

### 1. 组件初始化（Login.jsx）

```javascript
function Login() {
  // ① 初始化路由工具
  const navigate = useNavigate();
  
  // ② 初始化状态
  const [formData, setFormData] = useState({
    username: '',
    password: ''
  });
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState('');
  
  // ③ 渲染表单（用户看到登录界面）
  return (
    <form onSubmit={handleSubmit}>
      <input name="username" onChange={handleChange} />
      <input name="password" onChange={handleChange} />
      <button type="submit">登录</button>
    </form>
  );
}
```

### 2. 用户输入（触发 handleChange）

```javascript
// 用户在用户名输入框输入 "10001"
handleChange(e) {
  // e.target.name = "username"
  // e.target.value = "10001"
  
  setFormData({
    username: "10001",  // 更新状态
    password: ""
  });
}

// 用户在密码输入框输入 "123456"
handleChange(e) {
  setFormData({
    username: "10001",
    password: "123456"  // 更新状态
  });
}
```

### 3. 点击登录按钮（触发 handleSubmit）

```javascript
const handleSubmit = async (e) => {
  e.preventDefault();  // 阻止表单默认提交（避免页面刷新）
  
  // 前端验证
  if (!formData.username.trim()) {
    setError('请输入用户名或昵称');
    return;
  }
  
  setLoading(true);  // 按钮显示"登录中..."
  
  try {
    // 调用 API（核心）
    const result = await authAPI.login(
      formData.username,  // "10001"
      formData.password   // "123456"
    );
    
    // 处理响应
    if (result.code === 200) {
      localStorage.setItem('token', result.data.token);
      navigate('/');
    } else {
      setError(result.message);
    }
  } catch (err) {
    setError('网络错误');
  } finally {
    setLoading(false);
  }
};
```

## 网络传输过程

### HTTP 请求报文（浏览器 → 后端）

```http
POST /api/auth/login HTTP/1.1
Host: localhost:7070
Connection: keep-alive
Content-Length: 45
Content-Type: application/json
Origin: http://localhost:5173
Referer: http://localhost:5173/login

{"username":"10001","password":"123456"}
```

**关键点**：
- **跨域请求**：前端运行在 5173 端口，后端运行在 7070 端口，属于跨域
- **Origin 头**：浏览器自动添加，后端需要配置 CORS 允许跨域
- **Content-Type**：告诉后端请求体是 JSON 格式

### HTTP 响应报文（后端 → 浏览器）

```http
HTTP/1.1 200 OK
Content-Type: application/json;charset=UTF-8
Access-Control-Allow-Origin: http://localhost:5173
Access-Control-Allow-Credentials: true
Content-Length: 234

{"code":200,"message":"登录成功","data":{"token":"eyJhbGc...","username":"10001","nickname":"测试用户","role":"USER"}}
```

**关键点**：
- **Access-Control-Allow-Origin**：后端允许 5173 端口跨域访问
- **Content-Type**：返回 JSON 格式数据
- **HTTP 状态码**：200 表示成功（但业务成功与否看 code 字段）

## 后端处理流程

### 1. Spring Security 拦截

```java
// SecurityConfig.java
http.authorizeHttpRequests(auth -> auth
    .requestMatchers("/api/auth/login", "/api/auth/register").permitAll()  // 放行登录接口
    .anyRequest().authenticated()  // 其他接口需要认证
);
```

### 2. Controller 接收请求

```java
@PostMapping("/api/auth/login")
public Result<LoginResponse> login(@RequestBody LoginRequest request) {
    // Spring 自动反序列化 JSON 为 Java 对象
    // request.getUsername() → "10001"
    // request.getPassword() → "123456"
    
    LoginResponse response = authService.login(request);
    return Result.success(response, "登录成功");
}
```

### 3. Service 处理业务逻辑

```java
public LoginResponse login(LoginRequest request) {
    // ① 查询数据库
    User user = userMapper.selectByUsername(request.getUsername());
    if (user == null) {
        throw new AuthenticationException("用户不存在");
    }
    
    // ② 验证密码
    boolean matches = passwordEncoder.matches(
        request.getPassword(),  // 明文密码 "123456"
        user.getPassword()      // 数据库加密密码 "$2a$10$..."
    );
    if (!matches) {
        throw new AuthenticationException("密码错误");
    }
    
    // ③ 生成 Token
    String token = JwtUtil.generateToken(user.getUsername(), user.getRole());
    
    // ④ 返回结果
    return new LoginResponse(token, user.getUsername(), user.getNickname(), user.getRole());
}
```

### 4. 返回响应

```java
// Result.success() 封装返回数据
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGc...",
    "username": "10001",
    "nickname": "测试用户",
    "role": "USER"
  }
}
```

## 关键技术点对比

### 1. 数据存储对比

| 后端（Java） | 前端（JavaScript） | 作用 |
|-------------|-------------------|------|
| Session（服务器内存） | localStorage（浏览器） | 保存用户登录状态 |
| Redis（缓存） | sessionStorage（浏览器） | 临时存储（关闭浏览器清除） |
| MySQL（数据库） | IndexedDB（浏览器） | 大量结构化数据（很少用） |

### 2. 异步处理对比

| 后端（Java） | 前端（JavaScript） |
|-------------|-------------------|
| `CompletableFuture` | `async/await` |
| `@Async` 异步方法 | `Promise` |
| 线程池 | 浏览器事件循环 |

```java
// 后端异步
CompletableFuture.supplyAsync(() -> {
    return authService.login(request);
});
```

```javascript
// 前端异步
const result = await authAPI.login(username, password);
```

### 3. 路由跳转对比

| 后端（Spring Boot） | 前端（React Router） |
|--------------------|---------------------|
| `return "redirect:/"` | `navigate('/')` |
| `@RequestMapping` | `<Route path="/login" />` |
| URL 刷新页面（服务端渲染） | URL 变化不刷新（客户端渲染） |

### 4. 请求处理对比

| 后端（Spring MVC） | 前端（React） |
|-------------------|--------------|
| `@PostMapping` | `method: 'POST'` |
| `@RequestBody` | `body: JSON.stringify({...})` |
| `@RequestHeader` | `headers: { 'Authorization': ... }` |
| `@ResponseBody` | `response.json()` |

    log.info("收到登录请求: {}", request);  // 打印日志
    
    // 打断点调试
    LoginResponse response = authService.login(request);
    
    log.info("返回响应: {}", response);
    return Result.success(response, "登录成功");
}

## 常见问题排查

### 问题1：前端收到 CORS 错误

**错误信息**：
```
Access to fetch at 'http://localhost:7070/api/auth/login' from origin 'http://localhost:5173' 
has been blocked by CORS policy
```

**原因**：后端未配置跨域  
**解决**：在 `SecurityConfig.java` 添加 CORS 配置（项目已配置）

### 问题2：401 Unauthorized

**原因**：Token 过期或无效  
**排查**：
1. 检查 localStorage 是否有 token
2. 检查请求头是否有 `Authorization: Bearer {token}`
3. 重新登录获取新 Token

### 问题3：后端收不到请求

**排查步骤**：
1. 确认后端服务已启动（访问 http://localhost:7070/swagger-ui/index.html）
2. 确认前端 `.env.development` 中的 `VITE_API_BASE` 配置正确
3. 查看浏览器 Network 标签页的请求状态
