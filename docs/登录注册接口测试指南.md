# 登录/注册接口对接测试指南

## 测试前准备

### 1. 启动后端服务
```bash
cd backend
mvn spring-boot:run
```
确保后端运行在 `http://localhost:7070`

### 2. 启动前端服务
```bash
npm run dev
```
前端默认运行在 `http://localhost:5173`

---

## 前端测试步骤

### 测试1：用户注册

1. 访问 `http://localhost:5173/register`
2. 填写表单：
   - 昵称：`测试用户`
   - 密码：`123456`
   - 确认密码：`123456`
3. 点击"注册"按钮

**预期结果**：
- ✅ 显示绿色成功提示框
- ✅ 显示系统分配的用户名（如 `10001`）
- ✅ 浏览器控制台输出：`注册成功，用户名: 10001, Token: eyJ...`
- ✅ localStorage 中保存 `token`、`username`、`nickname`
- ✅ 3秒后自动跳转到首页
- ✅ Header 右上角显示用户名和"退出"按钮

**验证方法**：
```javascript
// 浏览器控制台执行
console.log({
  token: localStorage.getItem('token'),
  username: localStorage.getItem('username'),
  nickname: localStorage.getItem('nickname')
});
```

### 测试6：表单验证

**注册页面验证**：
- 昵称为空 → 提示"请输入昵称"
- 昵称太短（1个字符）→ 提示"昵称长度应在 2-20 个字符之间"
- 密码少于6位 → 提示"密码长度不能少于 6 位"

- 用户名为空 → 提示"请输入用户名或昵称"

## 后端接口测试（curl）

### 1. 注册接口

```bash
curl -X POST http://localhost:7070/api/auth/register \
  -H "Content-Type: application/json" \
  -d "{\"nickname\":\"curl测试\",\"password\":\"123456\"}"
```

**预期响应**：
```json
{
  "code": 200,
  "data": {
    "username": "10002",
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  },
  "message": "注册成功"
}
```

---

### 2. 登录接口（用户名）

```bash
curl -X POST http://localhost:7070/api/auth/login \
  -H "Content-Type: application/json" \
  -d "{\"username\":\"10002\",\"password\":\"123456\"}"
```

**预期响应**：
```json
{
  "code": 200,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  },
  "message": "登录成功"
}
```

---

### 3. 登录接口（昵称）

```bash
curl -X POST http://localhost:7070/api/auth/login \
  -H "Content-Type: application/json" \
  -d "{\"username\":\"curl测试\",\"password\":\"123456\"}"
```

**预期响应**：与上面相同

---

### 4. 退出登录接口

```bash
# 先登录获取 token，然后替换下面的 {YOUR_TOKEN}
curl -X POST http://localhost:7070/api/auth/logout \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer {YOUR_TOKEN}"
```

**预期响应**：
```json
{
  "code": 200,
  "data": null,
  "message": "退出登录成功"
}
```

---

### 5. 错误场景测试

**密码错误**：
```bash

  -H "Content-Type: application/json" \
  -d "{\"username\":\"10002\",\"password\":\"wrong_password\"}"
```

**预期响应**：

```json
  "code": 401,

  "message": "用户名或密码错误"
```

```bash
  -H "Content-Type: application/json" \
  -d "{\"nickname\":\"curl测试\",\"password\":\"123456\"}"
```

**预期响应**：
```json

  "code": 400,
  "data": null,
  "message": "昵称已被使用"
}
```

## 常见问题排查

### 问题1：前端无法连接后端

**症状**：控制台显示 `ERR_CONNECTION_REFUSED` 或 `Failed to fetch`

**排查步骤**：
1. 确认后端是否启动：访问 `http://localhost:7070/swagger-ui/index.html`
2. 检查环境变量配置：`.env.development` 中 `VITE_API_BASE` 是否正确
3. 重启前端服务（环境变量更改后需重启）

---

### 问题2：登录后 Header 不显示用户名

**排查步骤**：
1. 检查 localStorage：执行 `localStorage.getItem('token')`
2. 刷新页面触发 Header 的 useEffect
3. 检查浏览器控制台是否有报错

---

### 问题3：Token 无效

**症状**：退出登录或其他需要认证的接口返回 401

**排查步骤**：
1. 检查 Token 是否正确保存在 localStorage
2. 检查请求头是否包含 `Authorization: Bearer {token}`
3. Token 可能已过期（默认24小时），重新登录获取新 Token
