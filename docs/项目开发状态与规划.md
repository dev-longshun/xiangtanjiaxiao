## 项目概述

**湘潭驾校评价平台**是一个为湘潭地区学员提供真实驾校信息和评价的 Web 平台。项目经历了从纯前端静态网站到前后端分离架构的演进。

### 核心功能
- 驾校信息展示与对比
- 用户评价投稿与审核
- 管理后台（驾校管理、评价审核）
- 微信网页授权登录

#### 2. 评价审核后自动更新驾校评分（优先级：P0）

**描述**：当管理员审核通过评价后，需要自动更新关联驾校的 `rating` 和 `review_count`。

**需要修改的文件**：
- `ReviewService.java` - `reviewApproval` 方法

**实现逻辑**：
```java
public void reviewApproval(Long reviewId, boolean approved) {
    Review review = reviewMapper.selectById(reviewId);
    if (review == null) return;
    
    // 更新审核状态
    review.setStatus(approved ? "APPROVED" : "REJECTED");
    reviewMapper.updateById(review);
    
    // 如果通过，更新驾校评分
    if (approved) {
        String schoolId = review.getSchoolId();
        
        // 计算该驾校所有已审核评价的平均分
        List<Review> approvedReviews = reviewMapper.selectApprovedBySchoolId(schoolId);
        double avgRating = approvedReviews.stream()
            .mapToInt(Review::getRating)
            .average()
            .orElse(0.0);
        
        // 更新驾校
        School school = schoolMapper.selectById(schoolId);
        school.setRating(BigDecimal.valueOf(avgRating));
        school.setReviewCount(approvedReviews.size());
        schoolMapper.updateById(school);
    }
}
```

**估计工时**：1天

#### 3. 分页查询支持（优先级：P1）

**描述**：当前所有列表接口都是全量返回，数据量大时性能差，需支持分页。

**需要改造的接口**：
- `GET /api/schools` - 驾校列表分页
- `GET /api/reviews/school/{schoolId}` - 评价列表分页
- `GET /api/admin/reviews` - 待审核评价分页

**技术方案**：
使用 MyBatis-Plus 的 `Page` 插件。

```java
@GetMapping
public ResponseEntity<Page<School>> getAllSchools(
    @RequestParam(defaultValue = "1") int page,
    @RequestParam(defaultValue = "20") int size
) {
    Page<School> schoolPage = new Page<>(page, size);
    return ResponseEntity.ok(schoolService.page(schoolPage));
}
```

**估计工时**：1-2天

#### 4. 搜索功能增强（优先级：P2）

**描述**：当前搜索只支持按名称模糊查询，需支持更多条件。

**需要支持的搜索条件**：
- [ ] 按标签搜索（如"大型驾校"、"设施完善"）
- [ ] 按课程搜索（如"C1"、"C2"）
- [ ] 按评分范围筛选（如 4.5-5.0 分）
- [ ] 按地区筛选

**技术方案**：
使用 MyBatis-Plus 的 `QueryWrapper`。

```java
public List<School> searchSchools(SchoolSearchDTO dto) {
    QueryWrapper<School> qw = new QueryWrapper<>();
    
    if (dto.getKeyword() != null) {
        qw.like("name", dto.getKeyword());
    }
    
    if (dto.getTags() != null && !dto.getTags().isEmpty()) {
        // JSON 字段查询（MySQL 5.7+ 支持）
        qw.apply("JSON_CONTAINS(tags, {0})", JSON.toJSONString(dto.getTags()));
    }
    
    if (dto.getMinRating() != null) {
        qw.ge("rating", dto.getMinRating());
    }
    
    return schoolMapper.selectList(qw);
}
```

**估计工时**：2-3天

## 技术债务

### ⚠️ 安全问题

#### 1. 默认密码必须修改（P0）
- **问题**：初始管理员密码为 `123456`
- **风险**：生产环境易被攻击
- **解决方案**：
  - 首次登录强制修改密码
  - 或在部署文档中明确说明

---

#### 2. JWT 密钥需配置（P0）
- **问题**：`application.yml` 中有默认密钥
- **风险**：密钥泄露导致 Token 伪造
- **解决方案**：
  - 生产环境必须配置环境变量 `JWT_SECRET`
  - 使用强随机字符串（建议 32+ 字符）

---

#### 3. 微信凭证需配置（P0）
- **问题**：`WECHAT_APPID` 和 `WECHAT_SECRET` 未配置
- **风险**：无法使用微信登录
- **解决方案**：
  - 在微信开放平台/公众平台获取凭证
  - 配置环境变量

---

### ⚠️ 数据问题

#### 1. JSON 字段查询性能（P2）
- **问题**：`tags` 和 `courses` 使用 JSON 字段，复杂查询性能差
- **解决方案**：
  - 如需频繁按标签搜索，改为关联表设计
  - 或使用 MySQL 8.0 的 JSON 索引

---

#### 2. 数据备份策略（P1）
- **问题**：无自动备份机制
- **解决方案**：
  - 配置 MySQL 定时备份
  - 或使用云数据库的自动备份功能

---

### ⚠️ 性能问题

#### 1. 全量查询（P1）
- **问题**：所有列表接口未分页，数据量大时性能差
- **解决方案**：见 [分页查询支持](#3-分页查询支持优先级p1)

---

#### 2. N+1 查询（P2）
- **问题**：驾校详情页需关联查询评价，可能有 N+1 问题
- **解决方案**：
  - 使用 MyBatis 的 `<collection>` 一次性加载
  - 或使用 JOIN 查询
