## 全局说明

### 1. 基础信息

| 配置项 | 值 |
|--------|-----|
| 协议 | HTTP/HTTPS |
| 域名（开发环境） | `http://localhost:7070` |
| 域名（生产环境） | `https://your-domain.com`（待定） |
| 字符编码 | UTF-8 |
| 请求格式 | application/json |
| 响应格式 | application/json |

### 2. 请求头（Headers）

#### 公开接口（无需登录）
```http
Content-Type: application/json
```

#### 需要登录的接口
```http
Content-Type: application/json
Authorization: Bearer {JWT_TOKEN}
```

**说明**：
- JWT Token 从登录接口获取
- Token 有效期：24小时
- Token 失效后需重新登录

### 3. 统一响应格式

所有接口统一使用 Result 格式返回：

```json
{
  "code": 200,
  "data": {},  // 或数组 []，无数据时为 null
  "message": "操作成功"
}
```

**字段说明**：
| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 响应码（200=成功，其他=失败） |
| data | Object/Array | 响应数据（无数据时为 null） |
| message | String | 响应消息 |

#### 成功响应示例（200 OK）
```json
{
  "code": 200,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  },
  "message": "登录成功"
}
```

#### 错误响应示例（401/403/404/500）
```json
{
  "code": 401,
  "data": null,
  "message": "未授权，请先登录"
}
```

#### HTTP 状态码说明
| 状态码 | code 值 | 说明 |
|--------|---------|------|
| 200 | 200 | 请求成功 |
| 200 | 401 | 未授权（Token 失效或未登录） |
| 200 | 403 | 无权限（如普通用户访问管理接口） |
| 200 | 404 | 资源不存在 |
| 200 | 500 | 服务器内部错误 |

**注意**：HTTP 状态码始终为 200，通过 `code` 字段区分业务状态。

## 接口分组

### 一、认证接口（/api/auth）

#### 1.1 微信网页登录

**接口描述**：通过微信授权码登录（扫码或微信浏览器内授权）

**请求方式**：`POST`  
**请求路径**：`/api/auth/wechat/login`  
**是否需要登录**：否

**前端流程**：
```javascript
// 1. 跳转到微信授权页面
const WECHAT_AUTH_URL = 'https://open.weixin.qq.com/connect/qrconnect';
const params = {
  appid: 'YOUR_APPID',
  redirect_uri: encodeURIComponent('http://your-frontend.com/callback'),
  response_type: 'code',
  scope: 'snsapi_login',
  state: 'STATE'
};
window.location.href = `${WECHAT_AUTH_URL}?${new URLSearchParams(params)}#wechat_redirect`;

// 2. 用户授权后，微信回调到 redirect_uri，携带 code 参数
// 例如：http://your-frontend.com/callback?code=AUTHORIZATION_CODE&state=STATE

// 3. 前端从 URL 获取 code，调用后端接口
const urlParams = new URLSearchParams(window.location.search);
const code = urlParams.get('code');

fetch('http://localhost:7070/api/auth/wechat/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ code: code })
})
.then(res => res.json())
.then(result => {
  if (result.code === 200) {
    localStorage.setItem('token', result.data.token);
    console.log('登录成功', result.data.userInfo);
  } else {
    console.error(result.message);
  }
});
```

**请求参数**（Body - JSON）：
```json
{
  "code": "微信授权码（从回调 URL 参数中获取）"
}
```

**成功响应示例**（200 OK）：
```json
{
  "code": 200,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "userInfo": {
      "nickname": "张三",
      "avatar": "https://thirdwx.qlogo.cn/..."
    }
  },
  "message": "登录成功"
}
```

**错误响应示例**（401 Unauthorized）：
```json
{
  "code": 401,
  "data": null,
  "message": "微信授权失败，请重试"
}
```

```javascript
        school.examData = JSON.parse(school.examData); // {\"subject1\":95.5}
      });
      console.log(schools);
    } else {
      console.error(result.message);
    }
  });
```

### 三、评价接口（/api/reviews）

#### 3.1 提交评价

**接口描述**：用户投稿新评价（需要登录，默认待审核）

**请求方式**：`POST`  
**请求路径**：`/api/reviews`  
**是否需要登录**：是（ROLE_USER 或 ROLE_ADMIN）

**请求头**：
```http
Content-Type: application/json
Authorization: Bearer {JWT_TOKEN}
```

**请求参数**（Body - JSON）：
```json
{
  "schoolId": "changsha-anjia",
  "author": "张三",
  "content": "教练很负责，考试通过率高!",
  "rating": 5,
  "evidenceImages": [
    "/uploads/reviews/202511/abc123def456.jpg",
    "/uploads/reviews/202511/xyz789uvw012.jpg"
  ]
}
```

**字段说明**：
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| schoolId | String | 是 | 驾校ID |
| author | String | 是 | 评价者昵称 |
| content | String | 是 | 评价内容 |
| rating | Integer | 是 | 评分（1-5） |
| evidenceImages | Array<String> | 否 | 事实证明图片URL数组（最多9张，需先调用上传接口） |

**前端提交流程**：
```javascript
// 1. 用户选择图片后，先调用上传接口获取 URL
const uploadedUrls = [];
for (const file of files) {
  const formData = new FormData();
  formData.append('file', file);
  
  const uploadRes = await fetch('http://localhost:7070/api/upload/image', {
    method: 'POST',
    headers: { 'Authorization': 'Bearer ' + token },
    body: formData
  });
  const uploadResult = await uploadRes.json();
  if (uploadResult.code === 200) {
    uploadedUrls.push(uploadResult.data); // 保存图片 URL
  }
}

// 2. 提交评论时，将图片 URL 数组一起提交
const reviewData = {
  schoolId: 'changsha-anjia',
  author: '张三',
  content: '教练很负责！',
  rating: 5,
  evidenceImages: uploadedUrls // 图片URL数组
};

fetch('http://localhost:7070/api/reviews', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer ' + token
  },
  body: JSON.stringify(reviewData)
});
```

**成功响应示例**（200 OK）：
```json
{
  "code": 200,
  "data": null,
  "message": "评价已提交，等待管理员审核"
}
```

**错误响应示例**（401 Unauthorized）：
```json
{
  "code": 401,
  "data": null,
  "message": "未授权，请先登录"
}
```

### 四、文件上传接口（/api/upload）

#### 4.1 上传图片

**接口描述**：上传评论事实证明图片（需要登录）

**请求方式**：`POST`  
**请求路径**：`/api/upload/image`  
**是否需要登录**：是（ROLE_USER 或 ROLE_ADMIN）

**请求头**：
```http
Content-Type: multipart/form-data
Authorization: Bearer {JWT_TOKEN}
```

**请求参数**（Form Data）：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | File | 是 | 图片文件（最大5MB，支持 jpg/jpeg/png/gif/webp/bmp） |

**请求示例（JavaScript Fetch）**：
```javascript
const formData = new FormData();
formData.append('file', fileInput.files[0]);

fetch('http://localhost:7070/api/upload/image', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer ' + token
  },
  body: formData
})
.then(res => res.json())
.then(result => {
  if (result.code === 200) {
    const imageUrl = result.data; // "/uploads/reviews/202511/abc123.jpg"
    console.log('上传成功，图片URL:', imageUrl);
    // 保存 URL，稍后提交评论时使用
  } else {
    console.error('上传失败:', result.message);
  }
});
```

**请求示例（Apifox）**：
```
POST /api/upload/image
Headers:
  Authorization: Bearer {{token}}

Body (form-data):
  file: [选择文件]
```

**成功响应示例**（200 OK）：
```json
{
  "code": 200,
  "data": "/uploads/reviews/202511/a1b2c3d4e5f6.jpg",
  "message": "操作成功"
}
```

**错误响应示例**：

1. **文件过大**（400 Bad Request）：
```json
{
  "code": 400,
  "data": null,
  "message": "文件大小超过限制（最大 5MB）"
}
```

2. **文件格式不支持**（400 Bad Request）：
```json
{
  "code": 400,
  "data": null,
  "message": "不支持的文件格式，仅支持: jpg, jpeg, png, gif, webp, bmp"
}
```

3. **文件为空**（400 Bad Request）：
```json
{
  "code": 400,
  "data": null,
  "message": "文件不能为空"
}
```

4. **未登录**（401 Unauthorized）：
```json
{
  "code": 401,
  "data": null,
  "message": "未授权，请先登录"
}
```

**使用说明**：
- 单次上传1张图片，单张最大5MB
- 每条评论最多上传9张图片（需多次调用此接口）
- 返回的 URL 为相对路径（如 `/uploads/reviews/202511/xxx.jpg`）
- 前端显示时需拼接完整 URL：`http://localhost:7070/uploads/reviews/202511/xxx.jpg`
- 图片保存路径：`uploads/reviews/YYYYMM/随机文件名.扩展名`

## 环境变量配置

### 开发环境

在 Apifox 中创建「开发环境」，配置以下变量：

| 变量名 | 值 | 说明 |
|--------|-----|------|
| base_url | `http://localhost:7070` | 后端地址 |
| token | `（登录后自动获取）` | JWT Token |

### 前置脚本（自动保存 Token）

在「管理员登录」和「微信登录」接口的「后置操作」中添加：

```javascript
// 自动保存 Token 到环境变量
const res = pm.response.json();
if (res.code === 200 && res.data && res.data.token) {
  pm.environment.set("token", res.data.token);
  console.log("Token 已保存:", res.data.token);
}
```

### 全局请求头

在「环境」→「公共请求头」中添加：

```http
Authorization: Bearer {{token}}
```

这样所有需要登录的接口会自动携带 Token。

## 常见问题（FAQ）

### Q1: 为什么访问接口返回 401？
**A**: 需要登录的接口必须在请求头中携带 `Authorization: Bearer {token}`，请先调用登录接口获取 Token。

### Q2: JSON 字符串字段（tags、courses、examData）如何处理？
**A**: 后端返回的是 JSON 字符串，前端需要使用 `JSON.parse()` 解析：
```javascript
school.tags = JSON.parse(school.tags); // ["大型驾校","设施完善"]
```

### Q3: 如何测试微信登录？
**A**: 微信登录需要真实的微信授权码（code），测试环境可以：
1. 配置微信开放平台测试号
2. 使用 Postman/Apifox 手动模拟回调，获取 code
3. 或暂时跳过微信登录，直接用管理员登录测试其他功能

### Q4: 管理接口返回 403 无权限？
**A**: 确保使用管理员账号登录（`admin/123456`），普通用户 Token 无法访问管理接口。

### Q5: 驾校 ID 格式有要求吗？
**A**: 建议使用小写拼音+中划线格式，如 `changsha-anjia`，保持 URL 友好且易读。

## 附录：数据模型

### School（驾校）

```typescript
interface School {
  id: string;              // 驾校ID（如 "changsha-anjia"）
  name: string;            // 驾校名称
  namePinyin: string;      // 名称拼音
  rating: number;          // 综合评分（0.0-5.0）
  reviewCount: number;     // 评价总数
  passRate: number;        // 通过率（百分比）
  tags: string;            // 标签（JSON 数组字符串）
  courses: string;         // 开设课程（JSON 数组字符串）
  address: string;         // 地址
  phone: string;           // 联系电话
  businessHours: string;   // 营业时间
  priceRange: string;      // 学车费用范围
  examData: string;        // 考试数据（JSON 对象字符串）
  description: string;     // 驾校简介
  createdAt: string;       // 创建时间（ISO 8601）
  updatedAt: string;       // 更新时间（ISO 8601）
  isActive: number;        // 是否激活（1=激活, 0=已删除）
}
```

```typescript
interface Review {
```
