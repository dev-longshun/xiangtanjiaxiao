## 全局说明

### 1. 基础信息

| 配置项 | 值 |
|--------|-----|
| 协议 | HTTP/HTTPS |
| 域名（开发环境） | `http://localhost:7070` |
| 域名（生产环境） | `https://your-domain.com`（待定） |
| 字符编码 | UTF-8 |
| 请求格式 | application/json |
| 响应格式 | application/json |

### 2. 请求头（Headers）

#### 公开接口（无需登录）
```http
Content-Type: application/json
```

#### 需要登录的接口
```http
Content-Type: application/json
Authorization: Bearer {JWT_TOKEN}
```

**说明**：
- JWT Token 从登录接口获取
- Token 有效期：24小时
- Token 失效后需重新登录

### 3. 统一响应格式
 
所有接口统一使用 Result 格式返回：

```json
{
  "code": 200,
  "data": {},  // 或数组 []，无数据时为 null
  "message": "操作成功"
}
```

**字段说明**：
| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 响应码（200=成功，其他=失败） |
| data | Object/Array | 响应数据（无数据时为 null） |
| message | String | 响应消息 |

#### 成功响应示例（200 OK）
```json
{
  "code": 200,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  },
  "message": "登录成功"
}
```

#### 错误响应示例（401/403/404/500）
```json
{
  "code": 401,
  "data": null,
  "message": "未授权，请先登录"
}
```

#### HTTP 状态码说明
| 状态码 | code 值 | 说明 |
|--------|---------|------|
| 200 | 200 | 请求成功 |
| 200 | 401 | 未授权（Token 失效或未登录） |
| 200 | 403 | 无权限（如普通用户访问管理接口） |
| 200 | 404 | 资源不存在 |
| 200 | 500 | 服务器内部错误 |

**注意**：HTTP 状态码始终为 200，通过 `code` 字段区分业务状态。

## 接口分组

### 一、认证接口（/api/auth）

#### 1.1 用户注册

**接口描述**：用户通过昵称和密码注册新账号，系统自动生成用户名（数字ID）

**请求方式**：`POST`  
**请求路径**：`/api/auth/register`  
**是否需要登录**：否

**请求参数**（Body - JSON）：
```json
{
  "nickname": "张三",
  "password": "123456"
}
```

**字段说明**：
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| nickname | String | 是 | 昵称（用于评论展示，长度不超过50） |
| password | String | 是 | 密码（长度不少于6位） |

**成功响应示例**（200 OK）：
```json
{
  "code": 200,
  "data": {
    "username": "10001",
    "nickname": "张三",
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  },
  "message": "注册成功"
}
```

**错误响应示例**：

1. **昵称为空**（400 Bad Request）：
```json
{
  "code": 400,
  "data": null,
  "message": "昵称不能为空"
}
```

2. **昵称已被占用**（400 Bad Request）：
```json
{
  "code": 400,
  "data": null,
  "message": "昵称已被使用，请更换"
}
```

3. **密码过短**（400 Bad Request）：
```json
{
  "code": 400,
  "data": null,
  "message": "密码长度不能少于6位"
}
```

**前端示例代码**：
```javascript
fetch('http://localhost:7070/api/auth/register', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    nickname: '张三',
    password: '123456'
  })
})
.then(res => res.json())
.then(result => {
  if (result.code === 200) {
    // 保存用户名和 Token
    localStorage.setItem('username', result.data.username); // "10001"
    localStorage.setItem('token', result.data.token);
    alert('注册成功！您的用户名是：' + result.data.username + '，请妥善保管用于登录');
  } else {
    alert(result.message);
  }
});
```

#### 1.2 用户登录

**接口描述**：用户通过系统生成的用户名（数字ID）或唯一昵称和密码登录

**请求方式**：`POST`  
**请求路径**：`/api/auth/login`  
**是否需要登录**：否

**请求参数**（Body - JSON）：
```json
{
  "username": "10001",
  "password": "123456"
}
```

或使用昵称登录：
```json
{
  "username": "张三",
  "password": "123456"
}
```

**字段说明**：
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | String | 是 | 用户名（系统生成的数字ID）或唯一昵称 |
| password | String | 是 | 密码 |

**重要说明**：
- `username` 字段支持填写系统用户名（如 `10001`）或昵称（如 `张三`）
- 后端会先按用户名查询，若未找到则按昵称查询
- 昵称在系统中是唯一的，不会冲突

**成功响应示例**（200 OK）：
```json
{
  "code": 200,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  },
  "message": "登录成功"
}
```

**错误响应示例**（401 Unauthorized）：
```json
{
  "code": 401,
  "data": null,
  "message": "用户名或密码错误"
}
```

**前端示例代码**：
```javascript
// 方式1：使用系统用户名登录
fetch('http://localhost:7070/api/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    username: '10001',  // 系统生成的数字ID
    password: '123456'
  })
})
.then(res => res.json())
.then(result => {
  if (result.code === 200) {
    localStorage.setItem('token', result.data.token);
    console.log('登录成功');
  } else {
    alert(result.message);
  }
});

// 方式2：使用昵称登录（v1.2 新增）
fetch('http://localhost:7070/api/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    username: '张三',  // 使用昵称
    password: '123456'
  })
})
.then(res => res.json())
.then(result => {
  if (result.code === 200) {
    localStorage.setItem('token', result.data.token);
    console.log('登录成功');
  } else {
    alert(result.message);
  }
});
```

```json
      "reviewCount": 128,
      "passRate": 85.5,
      "tags": "[\"大型驾校\",\"设施完善\"]",
      "courses": "[\"C1\",\"C2\"]",
      "address": "长沙市岳麓区某某路123号",
      "phone": "0731-88888888",
      "businessHours": "周一至周日 8:00-18:00",
      "priceRange": "3000-4000元",
      "examData": "{\"subject1\":95.5,\"subject2\":88.3}",
      "description": "驾校简介...",
      "createdAt": "2024-01-01T08:00:00",
      "updatedAt": "2024-01-01T08:00:00",
```

**字段说明**：
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 驾校唯一标识（如 "changsha-anjia"） |
| name | String | 驾校名称 |
| namePinyin | String | 名称拼音（用于排序） |
| rating | Double | 综合评分（0.0-5.0） |
| reviewCount | Integer | 评价总数 |
| passRate | Double | 通过率（百分比，如 85.5） |
| tags | String | 标签（JSON 数组字符串） |
| courses | String | 开设课程（JSON 数组字符串） |
| address | String | 地址 |
| phone | String | 联系电话 |
| businessHours | String | 营业时间 |
| priceRange | String | 学车费用范围 |
| examData | String | 考试数据（JSON 对象字符串） |
| description | String | 驾校简介 |

**前端解析示例**：
```javascript
fetch('http://localhost:7070/api/schools')
  .then(res => res.json())
  .then(result => {
    if (result.code === 200) {
      const schools = result.data;
      schools.forEach(school => {
        // JSON 字符串需要解析
        school.tags = JSON.parse(school.tags);       // [\"\u5927\u578b\u9a7e\u6821\",\"\u8bbe\u65bd\u5b8c\u5584\"]
        school.courses = JSON.parse(school.courses); // [\"C1\",\"C2\"]
        school.examData = JSON.parse(school.examData); // {\"subject1\":95.5}
      });
      console.log(schools);
    } else {
      console.error(result.message);
    }
  });
```

### 三、评价接口（/api/reviews）

#### 3.1 提交评价

**接口描述**：用户投稿新评价（需要登录，默认待审核）

**请求方式**：`POST`  
**请求路径**：`/api/reviews`  
**是否需要登录**：是（ROLE_USER 或 ROLE_ADMIN）

**请求头**：
```http
Content-Type: application/json
Authorization: Bearer {JWT_TOKEN}
```

**请求参数**（Body - JSON）：
```json
{
  "schoolId": "changsha-anjia",
  "author": "张三",
  "content": "教练很负责，考试通过率高!",
  "rating": 5,
  "evidenceImages": [
    "/uploads/reviews/202511/abc123def456.jpg",
    "/uploads/reviews/202511/xyz789uvw012.jpg"
  ]
}
```

**字段说明**：
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| schoolId | String | 是 | 驾校ID |
| author | String | 是 | 评价者昵称 |
| content | String | 是 | 评价内容 |
| rating | Integer | 是 | 评分（1-5） |
| evidenceImages | Array<String> | 否 | 事实证明图片URL数组（最多9张，需先调用上传接口） |

**前端提交流程**：
```javascript
// 1. 用户选择图片后，先调用上传接口获取 URL
const uploadedUrls = [];
for (const file of files) {
  const formData = new FormData();
  formData.append('file', file);
  
  const uploadRes = await fetch('http://localhost:7070/api/upload/image', {
    method: 'POST',
    headers: { 'Authorization': 'Bearer ' + token },
    body: formData
  });
  const uploadResult = await uploadRes.json();
  if (uploadResult.code === 200) {
    uploadedUrls.push(uploadResult.data); // 保存图片 URL
  }
}

// 2. 提交评论时，将图片 URL 数组一起提交
const reviewData = {
  schoolId: 'changsha-anjia',
  author: '张三',
  content: '教练很负责！',
  rating: 5,
  evidenceImages: uploadedUrls // 图片URL数组
};

fetch('http://localhost:7070/api/reviews', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer ' + token
  },
  body: JSON.stringify(reviewData)
});
```

**成功响应示例**（200 OK）：
```json
{
  "code": 200,
  "data": null,
  "message": "评价已提交，等待管理员审核"
}
```

**错误响应示例**（401 Unauthorized）：
```json
{
  "code": 401,
  "data": null,
  "message": "未授权，请先登录"
}
```

### 四、文件上传接口（/api/upload）

#### 4.1 上传图片

**接口描述**：上传评论事实证明图片（需要登录）

**请求方式**：`POST`  
**请求路径**：`/api/upload/image`  
**是否需要登录**：是（ROLE_USER 或 ROLE_ADMIN）

**请求头**：
```http
Content-Type: multipart/form-data
Authorization: Bearer {JWT_TOKEN}
```

**请求参数**（Form Data）：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | File | 是 | 图片文件（最大5MB，支持 jpg/jpeg/png/gif/webp/bmp） |

**请求示例（JavaScript Fetch）**：
```javascript
const formData = new FormData();
formData.append('file', fileInput.files[0]);

fetch('http://localhost:7070/api/upload/image', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer ' + token
  },
  body: formData
})
.then(res => res.json())
.then(result => {
  if (result.code === 200) {
    const imageUrl = result.data; // "/uploads/reviews/202511/abc123.jpg"
    console.log('上传成功，图片URL:', imageUrl);
    // 保存 URL，稍后提交评论时使用
  } else {
    console.error('上传失败:', result.message);
  }
});
```

**请求示例（Apifox）**：
```

Headers:
  Authorization: Bearer {{token}}

Body (form-data):
  file: [选择文件]
```

**成功响应示例**（200 OK）：

3. **文件为空**（400 Bad Request）：
```json

  "code": 400,
```

| 参数 | 类型 | 必填 | 说明 |

1. **昵称已被占用**（400 Bad Request）：
```json
{
  "code": 400,
  "data": null,
  "message": "昵称已被其他用户使用，请更换"
```

```json
{
  "code": 400,
```

```json
  "code": 403,
```

## 环境变量配置

### 开发环境

在 Apifox 中创建「开发环境」，配置以下变量：

| 变量名 | 值 | 说明 |
|--------|-----|------|
| base_url | `http://localhost:7070` | 后端地址 |
| token | `（登录后自动获取）` | JWT Token |

### 前置脚本（自动保存 Token）

在「用户登录」和「管理员登录」接口的「后置操作」中添加：

```javascript
// 自动保存 Token 到环境变量
const res = pm.response.json();
if (res.code === 200 && res.data && res.data.token) {
  pm.environment.set("token", res.data.token);
  console.log("Token 已保存:", res.data.token);
}
```

### 全局请求头

在「环境」→「公共请求头」中添加：

```http
Authorization: Bearer {{token}}
```

这样所有需要登录的接口会自动携带 Token。

## 常见问题（FAQ）

### Q1: 为什么访问接口返回 401？
**A**: 需要登录的接口必须在请求头中携带 `Authorization: Bearer {token}`，请先调用登录接口获取 Token。

### Q2: JSON 字符串字段（tags、courses、examData）如何处理？
**A**: 后端返回的是 JSON 字符串，前端需要使用 `JSON.parse()` 解析：
```javascript
school.tags = JSON.parse(school.tags); // ["大型驾校","设施完善"]
```

### Q3: 如何测试用户注册和登录？
**A**: 可以直接使用 Apifox 或 Postman 测试：
1. 调用 `/api/auth/register` 注册新用户，记录返回的用户名（如 `10001`）
2. 调用 `/api/auth/login` 用用户名和密码登录
3. 使用返回的 Token 测试其他接口（如提交评价）

### Q4: 管理接口返回 403 无权限？
**A**: 确保使用管理员账号登录（`admin/123456`），普通用户 Token 无法访问管理接口。

### Q5: 驾校 ID 格式有要求吗？
**A**: 建议使用小写拼音+中划线格式，如 `changsha-anjia`，保持 URL 友好且易读。

## 附录：数据模型

### School（驾校）

```typescript
interface School {
  id: string;              // 驾校ID（如 "changsha-anjia"）

  address: string;         // 地址

  businessHours: string;   // 营业时间
  priceRange: string;      // 学车费用范围
  examData: string;        // 考试数据（JSON 对象字符串）
  description: string;     // 驾校简介
  createdAt: string;       // 创建时间（ISO 8601）
  updatedAt: string;       // 更新时间（ISO 8601）
  isActive: number;        // 是否激活（1=激活, 0=已删除）
}
```
