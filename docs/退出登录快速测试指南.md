## 二、在 Swagger UI 中测试

### 步骤1：用户登录

1. 打开 Swagger UI
2. 找到 **认证接口 → POST /api/auth/login**
3. 点击 **Try it out**
4. 在 Body 中输入：
```json
{
  "username": "10001",
  "password": "123456"
}
```
5. 点击 **Execute**
6. **复制返回的 Token**（从 `data.token` 字段）

### 步骤2：配置 Swagger 认证

1. 点击页面右上角 **Authorize** 🔓 按钮
2. 在弹窗中找到 **bearerAuth** 部分
3. 在 **Value** 输入框中粘贴 Token
   - ⚠️ **不要加 "Bearer " 前缀**
4. 点击 **Authorize** 按钮
5. 点击 **Close** 关闭对话框

页面右上角的锁图标会变为 🔒

### 步骤3：调用退出登录接口

1. 找到 **认证接口 → POST /api/auth/logout**
2. 点击 **Try it out**
3. **不需要输入 Body 内容**，直接点击 **Execute**
4. 查看响应：
```json
{
  "code": 200,
  "data": null,
  "message": "退出登录成功"
}
```

### 步骤4：验证 Token 已失效

1. 找到任何需要登录的接口，例如 **评价接口 → GET /api/reviews/my**
2. 点击 **Try it out**
3. 点击 **Execute**
4. 查看响应，应该返回 401：
```json
{
  "code": 401,
  "data": null,
  "message": "未授权，请先登录"
}
```

这说明退出登录成功，旧 Token 已失效！

## 三、使用 cURL 命令行测试

### 完整流程

```bash
# 1. 登录获取 Token
curl -X POST http://localhost:7070/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"10001","password":"123456"}' \
  | jq '.data.token'

# 输出示例：
# "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."

# 2. 保存 Token 到环境变量
TOKEN=$(curl -s -X POST http://localhost:7070/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"10001","password":"123456"}' \
  | jq -r '.data.token')

echo "Token: $TOKEN"

# 3. 验证 Token 有效（调用受保护接口）
curl -X GET http://localhost:7070/api/reviews/my \
  -H "Authorization: Bearer $TOKEN"

# 输出示例：
# {"code":200,"data":[...],"message":"操作成功"}

# 4. 退出登录
curl -X POST http://localhost:7070/api/auth/logout \
  -H "Authorization: Bearer $TOKEN"

# 输出示例：
# {"code":200,"data":null,"message":"退出登录成功"}

# 5. 验证 Token 已失效
curl -X GET http://localhost:7070/api/reviews/my \
  -H "Authorization: Bearer $TOKEN"

# 输出示例（应该是 401）：
# {"code":401,"data":null,"message":"未授权，请先登录"}
```

## 五、前端集成示例

### React 中的使用

```javascript
// 1. 登录函数
async function login(username, password) {
  const response = await fetch('http://localhost:7070/api/auth/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ username, password })
  });
  
  const result = await response.json();
  if (result.code === 200) {
    localStorage.setItem('token', result.data.token);
    localStorage.setItem('username', username);
    return true;
  }
  return false;
}

// 2. 带 Token 的 API 调用
function apiCall(url, options = {}) {
  const token = localStorage.getItem('token');
  
  return fetch(url, {
    ...options,
    headers: {
      ...options.headers,
      'Content-Type': 'application/json',
      'Authorization': 'Bearer ' + token
    }
  });
}

// 3. 退出登录函数
async function logout() {
  const token = localStorage.getItem('token');
  
  try {
    const response = await apiCall('http://localhost:7070/api/auth/logout', {
      method: 'POST'
    });
    
    const result = await response.json();
    
    if (response.status === 200 || result.code === 200) {
      console.log('退出登录成功');
    } else {
      console.warn('后端退出失败，但将清除本地 Token');
    }
  } catch (error) {
    console.error('退出登录异常:', error);
  } finally {
    // 无论成功或失败，都清除本地数据
    localStorage.removeItem('token');
    localStorage.removeItem('username');
    localStorage.removeItem('userId');
    localStorage.removeItem('nickname');
    
    // 跳转到登录页
    window.location.href = '/login';
  }
}

// 4. 使用示例
function LogoutButton() {
  return (
    <button onClick={logout}>
      退出登录
    </button>
  );
}
```

## 六、常见测试场景

### 场景1：正常退出流程

```
1. 登录 → 获取 Token ✓
2. 使用 Token 调用 API ✓
3. 退出登录 → Token 加入黑名单 ✓
4. 再次使用旧 Token 调用 API ✗ 返回 401
```

### 场景2：重复退出

```
1. 退出登录 ✓
2. 再次调用退出接口（使用旧 Token）
   → 返回 401："Token 无效或已过期"
```

### 场景3：使用过期 Token 退出

```
1. 使用已过期的 Token 调用退出接口
   → 返回 401："Token 无效或已过期"
```

### 场景4：不提供 Token

```
1. 不携带 Authorization 头直接调用退出接口
   → 返回 401："未找到有效的 Token"
```

## 八、故障排查

### 问题1：退出登录后，旧 Token 仍然可以使用

**原因**：可能是 TokenBlacklistManager 未注入到 JwtAuthenticationFilter

**解决方案**：
```java
// 检查 JwtAuthenticationFilter 中是否有以下字段
@Component
@RequiredArgsConstructor
public class JwtAuthenticationFilter extends OncePerRequestFilter {
    private final TokenBlacklistManager blacklistManager;  // 必须有
    // ...
}
```

### 问题2：退出登录接口返回 401

**原因1**：Token 已过期
- 解决：重新登录获取新 Token

**原因2**：Authorization 请求头格式错误
- 解决：格式应该是 `Authorization: Bearer {token}`
- 不能是：`Authorization: {token}`（缺少 "Bearer " 前缀）

**原因3**：Token 已被修改或损坏
- 解决：重新登录获取有效 Token

### 问题3：黑名单不断增长，内存占用过高

**原因**：清理线程未启动或清理效率低

**解决方案**：
1. 检查日志中是否有清理线程的输出
2. 如果内存问题严重，改用 Redis 存储黑名单
