# 前后端对接完成说明

## 一、后端补充

### 1.1 数据库调整

- `reviews` 表新增 `reject_reason` 字段，用于存储驳回原因

### 1.2 实体类调整

- `Review.java` 新增 `rejectReason` 字段

### 1.3 接口新增/调整

- `POST /api/admin/reviews/{id}/review` - 支持传入驳回原因
- `GET /api/admin/reviews/school/{schoolId}` - 获取驾校所有评价（含各状态）
- `DELETE /api/admin/reviews/{id}` - 删除评价
- `GET /api/reviews/my?author=xxx` - 获取用户的所有投稿

## 四、使用说明

### 4.1 开发环境启动

```bash
# 启动后端（需要先配置数据库）
cd backend
mvn spring-boot:run

# 启动前端
npm run dev
```

### 4.2 默认管理员账号

- 用户名: `admin`
- 密码: `123456`

### 4.3 API 地址配置

- 开发环境: `.env.development` 中配置 `VITE_API_BASE_URL`
- 生产环境: `.env.production` 中配置 `VITE_API_BASE_URL`
