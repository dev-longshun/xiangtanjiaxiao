# 微信网页登录集成指南

## 📱 登录方式说明

本项目支持两种微信网页登录方式：

### 1. **微信扫码登录**（PC 端推荐）
- 适用场景：电脑浏览器访问
- 用户体验：显示二维码，用户用微信扫码授权
- 无需在微信内打开网页

### 2. **微信浏览器内授权**（移动端）
- 适用场景：手机微信内打开网页
- 用户体验：直接弹出授权确认框
- 必须在微信浏览器内打开

## 🔧 后端配置

### 1. 获取微信凭证

#### **方式一：微信开放平台（推荐，支持扫码登录）**
1. 访问 [微信开放平台](https://open.weixin.qq.com/)
2. 注册开发者账号并认证（需要300元认证费）
3. 创建"网站应用"
4. 获取 `AppID` 和 `AppSecret`
5. 配置授权回调域名（如 `xiangtanjiaxiao.vercel.app`）

#### **方式二：微信公众平台（仅支持微信内授权）**
1. 访问 [微信公众平台](https://mp.weixin.qq.com/)
2. 注册服务号（订阅号不支持网页授权）
3. 获取 `AppID` 和 `AppSecret`
4. 在"接口权限"-"网页授权"中配置回调域名

### 2. 配置后端

在 `backend/src/main/resources/application.yml` 中配置：

```yaml
wechat:
  appid: wxXXXXXXXXXXXXXXXX      # 替换为你的 AppID
  secret: your-wechat-secret     # 替换为你的 AppSecret
```

或使用环境变量（推荐生产环境）：

```bash
export WECHAT_APPID=wxXXXXXXXXXXXXXXXX
export WECHAT_SECRET=your-wechat-secret
```

## 💻 前端实现

### **方式一：扫码登录（PC 端）**

#### 1. 创建登录按钮

```jsx
// src/components/WeChatLogin.jsx
import { useState } from 'react';

export default function WeChatLogin() {
  const [showQRCode, setShowQRCode] = useState(false);
  
  const handleLogin = () => {
    const appid = 'wxXXXXXXXXXXXXXXXX';  // 你的 AppID
    const redirectUri = encodeURIComponent('https://xiangtanjiaxiao.vercel.app/wechat/callback');
    const state = Math.random().toString(36).substring(7); // 防 CSRF 攻击
    
    // 跳转到微信扫码登录页面
    window.location.href = `https://open.weixin.qq.com/connect/qrconnect?` +
      `appid=${appid}&` +
      `redirect_uri=${redirectUri}&` +
      `response_type=code&` +
      `scope=snsapi_login&` +
      `state=${state}#wechat_redirect`;
  };
  
  return (
    <button onClick={handleLogin} className="wechat-login-btn">
      <img src="/wechat-icon.png" alt="微信" />
      微信登录
    </button>
  );
}
```

#### 2. 创建回调页面

```jsx
// src/pages/WeChatCallback.jsx
import { useEffect } from 'react';
import { useNavigate, useSearchParams } from 'react-router-dom';

export default function WeChatCallback() {
  const [searchParams] = useSearchParams();
  const navigate = useNavigate();
  
  useEffect(() => {
    const code = searchParams.get('code');
    const state = searchParams.get('state');
    
    if (code) {
      // 调用后端登录接口
      fetch('http://localhost:7070/api/auth/wechat/login', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ code })
      })
      .then(res => res.json())
      .then(data => {
        if (data.token) {
          // 保存 Token 和用户信息
          localStorage.setItem('token', data.token);
          localStorage.setItem('userInfo', JSON.stringify(data.userInfo));
          
          // 跳转到首页
          navigate('/');
        } else {
          alert('登录失败：' + (data.error || '未知错误'));
          navigate('/login');
        }
      })
      .catch(err => {
        console.error('登录失败:', err);
        navigate('/login');
      });
    }
  }, [searchParams, navigate]);
  
  return (
    <div className="loading">
      <p>登录中，请稍候...</p>
    </div>
  );
}
```

#### 3. 添加路由


### **方式二：微信浏览器内授权（移动端）**

#### 1. 检测是否在微信浏览器内

```javascript
function isWechatBrowser() {
  const ua = navigator.userAgent.toLowerCase();
  return /micromessenger/.test(ua);
}
```

#### 2. 微信内登录

```jsx
export default function WeChatLogin() {
  const handleLogin = () => {
    if (!isWechatBrowser()) {
      alert('请在微信中打开本页面');
      return;
    }
    
    const appid = 'wxXXXXXXXXXXXXXXXX';  // 你的 AppID（公众号）
    const redirectUri = encodeURIComponent('https://xiangtanjiaxiao.vercel.app/wechat/callback');
    const state = Math.random().toString(36).substring(7);
    
    // 微信浏览器内授权（静默授权 snsapi_base 或 需确认 snsapi_userinfo）
    window.location.href = `https://open.weixin.qq.com/connect/oauth2/authorize?` +
      `appid=${appid}&` +
      `redirect_uri=${redirectUri}&` +
      `response_type=code&` +
      `scope=snsapi_userinfo&` +  // 或 snsapi_base（静默授权）
      `state=${state}#wechat_redirect`;
  };
  
  return <button onClick={handleLogin}>微信登录</button>;
}
```

```jsx

import { useEffect, useRef } from 'react';

export default function WeChatLoginQR() {
  const qrRef = useRef(null);
  
  useEffect(() => {

      new window.WxLogin({
        id: qrRef.current.id,
```

## 🎯 完整流程示意图

```
用户点击"微信登录"
        ↓
前端跳转到微信授权页面
（PC 显示二维码 / 移动端微信内弹窗）
        ↓
用户扫码/确认授权
        ↓
微信重定向到 redirect_uri?code=XXX&state=YYY
        ↓
前端获取 code，调用后端接口
POST /api/auth/wechat/login { code }
        ↓
后端通过 code 换取 access_token
        ↓
后端获取用户信息（openid, nickname, avatar）
        ↓
后端查询/创建用户，生成 JWT Token
        ↓
返回 { token, userInfo }
        ↓
前端保存 Token 到 localStorage
        ↓
跳转到首页，登录完成 ✅
```

## 🔒 安全注意事项

1. **HTTPS 必须**：微信要求回调地址必须是 HTTPS（开发环境可使用 ngrok/localtunnel）
2. **State 参数**：防止 CSRF 攻击，建议生成随机字符串
3. **Token 保护**：不要在 URL 中传递敏感信息
4. **域名白名单**：在微信后台配置授权回调域名白名单

## 📋 API 接口文档

### **POST /api/auth/wechat/login**

**请求**
```json
{
  "code": "021xXxXxXxXxXxXx"  // 微信授权码
}
```

**响应（成功）**
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "userInfo": {
    "nickname": "张三",
    "avatar": "https://thirdwx.qlogo.cn/..."
  }
}
```

**响应（失败）**
```json
{
  "error": "微信授权失败，请重试"
}
```
